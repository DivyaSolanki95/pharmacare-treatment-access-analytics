# Project Requirements

## Business Objective

Build an end-to-end healthcare analytics solution to evaluate patient treatment access, treatment initiation, treatment delays, discontinuation, and provider-level performance.

## Core Business Questions

The project should answer:

1. How many diagnosed patients initiate treatment?
2. What percentage of patients remain untreated?
3. How long does it take patients to start treatment?
4. Where do access delays occur?
5. Does treatment initiation vary by insurance type?
6. Does treatment access vary by therapy area?
7. Does treatment performance vary by region?
8. Which providers show differences in treatment initiation and treatment timelines?
9. What patient access areas require further investigation?

## Data Requirements

The solution should contain synthetic data representing:

- Patients
- Healthcare providers
- Therapies
- Patient treatment journeys
- Access events

## Analytical Requirements

The analysis should include:

- Treatment initiation rate
- Treatment discontinuation rate
- Average time to treatment
- Access approval delay
- Insurance-level analysis
- Therapy-level analysis
- Regional analysis
- Provider-level analysis

## Technical Requirements

The project should demonstrate:

- Python/Pandas data processing
- Data validation
- Feature engineering
- SQL analytical queries
- MySQL data handling
- Power BI dashboard development
- DAX measures
- Git/GitHub project organization

## Dashboard Requirements

The Power BI solution should contain four pages:

### Page 1 — Executive Overview

High-level KPIs and treatment-access trends.

### Page 2 — Patient Access & Treatment Journey

Patient journey stages and access-delay analysis.

### Page 3 — Payer & Therapy Analysis

Insurance and therapy-level treatment access analysis.

### Page 4 — Provider Performance

Provider-level treatment initiation, treatment time, patient volume, and performance summary.

## Deliverables

The final project should contain:

- Raw synthetic datasets
- Processed analytical dataset
- Python scripts
- SQL analysis
- Power BI dashboard
- Business insights
- Data dictionary
- Methodology documentation
- Project README
